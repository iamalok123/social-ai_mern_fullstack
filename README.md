# Social Media Scheduler (MERN Stack)

A full-stack social media scheduling web application built using Node.js, Express, React, TypeScript, and Vite.

## Project Structure

```text
social-media_scheduler_fullstack_mern/
├── backend/            # Express.js REST API server
├── frontend/           # React + TypeScript + Vite frontend application
├── .gitignore          # Root Git ignore file
└── README.md           # Project documentation
```

## Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/) (v18+)
- npm or yarn

### Backend Setup
```bash
cd backend
npm install
npm start # or node index.js
```

### Frontend Setup
```bash
cd frontend
npm install
npm run dev
```
